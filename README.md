# p2-cfg README

## Features

This extension includes highlighting for:

- Comments
- Numbers
- Strings
- Console commands
- Special prefixes: **+**, **-**, and **$**
- Key terms like:
  - cond
  - sar_alias
  - alias
  - svar_set
  - exec
  - sar_function

Here is an example of the highlighting in action:

<img src="https://i.postimg.cc/g0BXsGfB/example.png" alt="Example">

**Note:** this extension does not add autocompletion or code snippets.

## Requirements

This extension highlights commands from the base game and the **Source Auto Record**, but the mod is not required for the extension to work.
